# Plugins Hub

MoPress features an open and extensible plugin ecosystem. Whether you are using Book mode or Site mode, plugins allow you to customize syntax extensions, asset pipelines, custom shortcodes, and integrations.

## Plugin Types

1. **External Process Plugins (CLI / Protocol)**: Language-agnostic executables or scripts that communicate with MoPress over stdin/stdout using standard JSON-RPC style protocols. Write plugins in Python, Node.js, Rust, Go, or shell scripts.
2. **Web Components**: Custom HTML elements for interactive documentation widgets, tabs, embedded previews, and reactive elements.
3. **MoonBit Native Modules**: High-performance in-process modules that link directly with MoPress steps and AST transformers without process boundary overhead.
