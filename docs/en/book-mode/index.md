# Book Mode

Book mode is inspired by mdBook, providing an out-of-the-box documentation site generator. Compared to mdBook, MoPress delivers extensive extensibility, a [lightweight template engine](../advance/template.md), an elegant default aesthetic, code and style injections, frontmatter metadata, and AST transformers.

## Key Sections

- [Configuration (`sena.toml`)](./configuration.md): Project metadata, i18n, output directories, and build flags.
- [Structuring Chapters (`SUMMARY.md`)](./summary-file.md): Navigation hierarchy, chapter titles, dividers, and nesting.
- [Frontmatter Metadata](./frontmatter.md): Page-specific metadata overrides, layouts, and custom variables.
- [Extension Configuration](./extensions.md): External preprocessors and AST transformers.
- [Feature Presets](./features.md): Built-in features like search, KaTeX, and code copy buttons.
- [Page Customization](./pages.md): Custom templates, stylesheet injections, and script inclusions.
