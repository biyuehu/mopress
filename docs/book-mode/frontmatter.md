# 元数据

元数据（frontmatter）是位于 Markdown 文件顶部、由 `---` 包裹的一段声明，用于描述这篇文章本身的属性，而不是文章正文的一部分。

## 基本语法

```markdown
---
title: 我的第一篇文章
---

# 正文从这里开始

这里是文章的实际内容。
```

`---` 之间的内容按 `字段名: 值`的形式书写，一行一个字段。元数据结束（第二个 `---`）之后的内容才是文章正文，会被作为 Markdown 解析渲染；元数据本身不会出现在最终渲染出的正文里。

## 可以写哪些字段

元数据并没有固定必填的字段列表，它本质上是一组自由的键值对。最常用、也几乎总会填写的是 `title`，用于表示这篇文章的标题，进而可能被模板用于页面的标题、页头等位置。

在 Book 模式中，内置的模板引擎与 Feed/Sitemap 生成器会识别以下常用字段（均为可选，有则用、无则回退或忽略）：

- `title`: 页面标题（若未指定则从目录 `SUMMARY.md` 的章节链接名中读取）
- `description`: 页面简介，用于 HTML `<meta name="description">` 与 Feed `<summary>`
- `keywords`: 页面关键词，以逗号分隔，用于 `<meta name="keywords">` 与 Feed 分类 `<category>`
- `authors`: 页面作者（支持多作者以逗号分隔），未指定时回退使用全局配置 `authors`
- `date`: 页面发布或最后修改时间，用于 Feed/Sitemap 中的时间戳；未指定时统一回退使用站点构建时间
- `language`: 页面语言，用于 HTML `lang` 属性及 Feed 的 `xml:lang`

除此之外，可以按模板需要声明任意自定义字段（如 `order`、`draft` 等），这些字段是否被使用、如何被使用，取决于站点所用的模板与处理管线是否读取了它们。

## 这些字段最终去了哪里

在 Book 模式下，一篇文章的元数据字段会在构建过程中被自动提取出来，成为该页面可用的模板变量——写在元数据里的 `title: 我的第一篇文章`，可以直接在模板中以变量的形式引用。这一步是 Book 模式内置处理管线自动完成的，不需要额外配置。

这只是 `模板变量从何而来` 这个更大话题的其中一个来源；模板变量的完整语法、渲染上下文的组成方式，请参见 [模板引擎](../advance/template.md) 相关说明。如果使用 Site 模式并且希望达到类似 `元数据自动变为模板变量` 的效果，这一步需要自己在处理管线中显式完成，具体做法参见 [组合 Steps](../site-mode/composing-steps.md) 相关说明。
